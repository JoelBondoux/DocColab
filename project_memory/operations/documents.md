# Document Management

> Maintained by AtlasMind (Project Dashboard → Documents). This is the human-readable
> mirror of `documents.json`; edit either and the other is kept in sync from the dashboard.

AtlasMind never rewrites your documents automatically. This file records **where**
documents live and **which** ones should be kept current, so the dashboard can flag
staleness and offer an assisted update you trigger explicitly.
